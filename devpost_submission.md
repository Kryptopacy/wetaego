## 1. Project Overview & Vision

The open web is undergoing its most profound evolutionary leap since the mobile revolution: the shift from point-and-click human browsing to **Human + Agent Collaborative Co-Browsing**. 

Today, while multinational e-commerce giants invest millions engineering proprietary agentic interfaces, millions of businesses worldwide—from independent solopreneurs and local service providers to multi-location enterprises and diverse commercial conglomerates—are locked out of the agentic economy. They exist behind unstructured HTML documents, custom JavaScript widgets, and fragmented checkout flows that browsing agents struggle to parse, configure, and transact on reliably.

**WETAEGO is the universal operating system for the next generation of commerce.**

Rather than building a brittle, single-purpose application with hardcoded endpoints, WETAEGO integrates the **Web Model Context Protocol (WebMCP)** at the **platform infrastructure layer**. 

WETAEGO features an **arbitrary-schema commercial engine** capable of supporting any commercial model:
* **Physical & Digital Retail**: Variant matrices (sizes, colors, materials, tech specs, inventory tracking).
* **Time-Slot & Resource Bookings**: Appointment scheduling, spa treatments, rentals, and table reservations.
* **Service Quotes & Diagnostics**: Multi-tier repair estimates, custom project requests, and consultation intakes.
* **Dynamic Rate Cards & Sponsorships**: Creator packages, media licensing, and B2B deliverables.
* **Hospitality & Dining**: Multi-course menus, dietary tagging, ingredient customization, and in-venue staff dispatch.

Any business that sets up on WETAEGO automatically inherits an autonomous, self-describing tool suite dynamically synthesized and registered onto `document.modelContext`. 

When an AI browsing agent (such as **ChatGPT Desktop In-App Browser** or **Google Chrome 149+ with `#enable-webmcp-testing`**) navigates to any WETAEGO merchant URL, the page instantly presents a live, deterministic, and bidirectional client-side tool API.

## 2. Why This Use Case is a Strong Fit for WebMCP

Real-world commerce and service scheduling are fundamentally **high-friction, multi-dimensional decision spaces**:

1. **Unbounded Multi-Constraint Problem Solving**: 
   Customers do not search with simple keywords; they search across intersecting multi-dimensional constraints:
   * *"Find an organic, anti-aging facial with LED therapy available this Saturday under $150."*
   * *"Order a halal-certified medium-rare steak with plantain fries, a seafood starter, and an alcohol-free craft cocktail under $75."*
   * *"Buy a 15-inch M3 laptop with 24GB RAM and 2-year accidental damage warranty."*
   * *"Book a diagnostic repair quote for an iPhone 15 with sapphire glass installation."*
2. **The Inherent Fragility of Vision and DOM Scraping**: 
   Traditional web scraping or screenshot-based clicking is slow, fragile, and fails when navigating multi-tiered variant pickers, dynamic pricing formulas, or multi-step checkout modals.
3. **The Universal Multiplier Effect**: 
   * A bespoke WebMCP implementation on a single website helps only that one brand.
   * **WETAEGO turns WebMCP into open web infrastructure**: A browsing agent navigating WETAEGO can transact with an automotive repair shop, an omakase restaurant, a luxury boutique, a medical clinic, or a rental loft using the exact same unified, standardized protocol.
4. **Zero-Latency In-Browser State Synchronization**: 
   Because WebMCP executes directly within the active client DOM session, tools possess immediate read/write access to client state, IndexedDB persistence, and Zustand stores without incurring the latency or security overhead of external third-party middleware.

## 3. How It Creates a Better User Experience

### 🎯 "Transact by Intent" (Goal-Oriented Browsing)
Instead of forcing human shoppers to manually click through multiple navigation categories, decipher dense spec sheets, or calculate add-on totals, they simply state their high-level intent:
> *"I have a $50 budget, I'm vegan and allergic to nuts, and I want dinner for two people with drinks."*

The agent executes `search_catalog` with attribute and budget filters, resolves ingredients via `get_item_details`, and populates the cart with exact customized selections in seconds.

### 👻 Live "Ghost in the Machine" Co-Browsing
External headless APIs sever the human from the experience. WETAEGO WebMCP provides **true shared context**:
* As the agent executes `add_to_cart` or `update_cart_quantity`, the human customer watches the browser UI react in real time—animated Sonner toasts appear (*"🤖 AI added 1x 24-Hour Suya Steak (Medium Rare, Truffle Plantain) to cart"*), the cart badge pulses, and the order drawer updates live.
* The human shopper and AI agent browse, curate, and customize the order simultaneously.

### 🛎️ In-Venue Service & Staff Dispatch
For physical dine-in, salon, clinic, or hotel guests, WebMCP exposes `call_staff_or_service`. A guest can simply prompt their device: *"Ask our server for extra water and napkins"*, and the page dispatches an immediate service ticket tagged with their exact table, seat, or room identifier.

## 4. What People and Agents Can Do Together That Was Difficult or Impossible Before

### 1. Arbitrary Polymorphic Variant & Modifier Navigation
Navigating complex, multi-tiered variant trees has historically broken AI agents. WETAEGO dynamically synthesizes structured JSON schemas allowing agents to resolve multi-dimensional configuration axes across any industry:
* **Custom Hardware & Electronics**: Storage Tiers (*256GB / 512GB / 1TB*), Titanium Finishes, and Multi-Year Warranty Add-ons.
* **Apparel & Luxury Retail**: Exact Sizing (*XS–XL / 38–45*), Colorways, Fabric Finishes, and Gold-Foil Monogramming.
* **Wellness & Professional Services**: Duration (*60m vs 90m*), Treatment Boosters, and Essential Oil Infusions.
* **Hospitality & Dining**: Cooking Doneness (*Medium Rare*), Regional Spice Levels, Dietary Preferences, and Complimentary Side Combinations.

### 2. The Architectural "Human-in-the-Loop" Safe Payment Gate (`initiate_checkout`)
A critical barrier to AI agent adoption in commerce is financial trust—users are hesitant to grant autonomous agents unrestricted access to credit cards.

WETAEGO solves this with a purpose-built **Human Confirmation Gate**:
* The agent conducts the heavy lifting of discovery, constraint filtering, modifier composition, and discount calculations.
* When ready, the agent calls `initiate_checkout`.
* Rather than auto-charging, the storefront presents a clean, pre-filled Order Review & Payment Modal directly in the viewport.
* The human customer reviews the items, verifies the total, and authorizes payment with a single biometric touch (Apple Pay / Google Pay / Card / Bank Transfer).

### 3. Multi-Concept Enterprise Conglomerates
Enterprises and multi-location franchises (exemplified by our pre-seeded enterprise demo, **Pacy Group**) frequently operate diverse multi-concept operations: dining, wellness, hospitality, luxury retail, and technical services under one unified brand. 

With WETAEGO WebMCP, an agent navigating a multi-concept portal seamlessly transitions between scheduling appointments, ordering physical items, and reserving accommodations in one continuous, friction-free browser session.

## 5. Technical Implementation & Architecture

WETAEGO is engineered with **Next.js 16 (App Router)**, **React 19**, **Zustand**, and **IndexedDB**.

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│                          Browser Agent (ChatGPT Desktop / Google Chrome 149+)                   │
└────────────────────────────────────────────────┬────────────────────────────────────────────────┘
                                                 │
                                                 ▼ document.modelContext.registerTool()
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                   WETAEGO WebMCP Bridge Layer                                   │
│                                                                                                 │
│  ┌──────────────────────────────┐   ┌───────────────────────────┐   ┌────────────────────────┐  │
│  │   Dynamic Tool Suite         │   │   Reactive State Bridge   │   │  Human Co-Browsing UI  │  │
│  │  - search_catalog            │───▶ - useCartStore (Zustand)  │───▶ - Live Sonner Toasts   │  │
│  │  - get_item_details          │   │ - IndexedDB Persistence   │   │ - Badge Animations     │  │
│  │  - add_to_cart (with mods)   │   │ - Staff Service Actions   │   │ - Cart Drawer Pop-out  │  │
│  │  - view_cart / update_cart   │   │ - Table / Seat Scoping    │   │ - Checkout Review Gate │  │
│  │  - call_staff_or_service     │   │                           │   │                        │  │
│  │  - initiate_checkout         │   │                           │   │                        │  │
│  └──────────────────────────────┘   └───────────────────────────┘   └────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
```

### Core Architecture Components:
1. **Universal Registry & Browser Polyfill (`lib/webmcp/registry.ts`, `lib/webmcp/types.ts`)**:
   * Direct interface to W3C `document.modelContext.registerTool` and `window.modelContext`.
   * Isomorphic fallback engine ensuring complete operational stability in development, automated CI environments, and standard browsers.
2. **Context-Aware Dynamic Tool Factory (`lib/webmcp/tools.ts`)**:
   * Evaluates the active tenant’s taxonomy, catalog items, modifier trees, currency, and table/room identifier.
   * Synthesizes 8 full-lifecycle tools with validated JSON Schema parameters.
3. **Platform Storefront Injector (`components/webmcp/webmcp-provider.tsx`)**:
   * Injected globally across public routes (`app/m/[slug]/page.tsx` and `app/m/[slug]/p/[pageSlug]/page.tsx`).
   * Automatically adapts to any business type and unregisters tools cleanly on page transitions.
4. **Interactive In-Browser WebMCP Playground (`components/webmcp/webmcp-tester.tsx`)**:
   * Floating tester badge (`⚡ WebMCP Tools`) embedded in every storefront.
   * Allows judges, developers, and users to trigger 1-click test scenarios, inspect raw JSON inputs and schema outputs, and observe instantaneous UI reactivity on any browser.
5. **Robust Automated Test Suite (`lib/webmcp/__tests__/webmcp.test.ts`)**:
   * 8 comprehensive Vitest integration tests validating search filtering, variant attachment, cart state persistence, bill splitting, and checkout handoff with 100% pass rate.
